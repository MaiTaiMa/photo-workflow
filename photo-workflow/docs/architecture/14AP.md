## 2. Benötigte Funktionen und Klassen

### `Dockerfile`

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY app/ ./app/
COPY config/ ./config/

ENTRYPOINT ["python", "-m", "app.cli"]
```

### `docker-compose.yml`

```yaml
version: "3.8"

services:
  workflow:
    build: .
    volumes:
      - ./config:/config:ro
      - ./NAS_EXAMPLE:/nas:rw
      - ./WORKFLOW_DATA/models:/models:ro
    environment:
      - WORKFLOW_CONFIG=/config/config.yaml
      - WORKFLOW_BASEDIR=/nas
      - WORKFLOW_MODELS=/models
```

## 6. Relevante Regeln aus v1.1

- **Ein verbindlicher Root-`requirements.txt`.**
- **Modelle und Laufzeitdaten liegen als NAS-Mounts, nicht im Image oder Git.**
- **Shell prüft nur Umgebung und startet `python -m app.cli`.**
- **Secrets werden ausschließlich als Umgebungsvariablen an den Container übergeben und nie in Config/Artefakten abgelegt.**
